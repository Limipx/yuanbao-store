# Lua 5.1 数学库缺失与实测坑

> 更新：2026-10-15（第三轮：静默失效类 bug 专章）
> 状态标注：【已测】= 实测确认　【未测】= 待验证
> **引擎为官方 Lua 5.1｜沙盒验证环境 lupa（Lua 5.1 C 实现）+ Lua 5.5**

## 一、数学库差异（按版本）

| 函数 | Lua 5.1 | Lua 5.5 | 建议 |
|---|---|---|---|
| `math.tanh` | ❌ **不存在** | ❌ 已移除 | **脚本内自带分段实现** |
| `math.pow` | ✅ 存在 | ❌ 已移除 | **统一用 `^` 运算符** |
| `math.log` | ✅ | ✅（5.2+ 需显式底数） | 注意参数差异 |
| `math.floor/ceil/abs/sqrt/exp` | ✅ | ✅ | 安全 |
| `math.random` | ✅ | ✅ | ⚠️ 需固定种子才确定性 |

### ⚠️ math.pow 让 8 个检测器全部静默失效

反作弊系统调试时 `math.pow` 不可用 → **全部 8 个检测器静默失效**：
脚本正常运行、不报错、**只是永远查不出作弊**。异常被 `pcall` 吞掉。

**这类 bug 看代码根本发现不了，只能靠实测。**

### tanh 的安全实现

```lua
local function _tanh(x)
    if x > 20 then return 1 end
    if x < -20 then return -1 end
    local e = math.exp(2 * x)     -- 不要写 exp(x)+exp(-x)，大 x 会溢出
    return (e - 1) / (e + 1)
end
```

## 二、⚠️ 静默失效类 bug（最高危）

以下全部**不报错、不崩溃，只是结果错**。是本轮实测抓到的真实案例。

### 1. pcall 吞异常

引擎里 `error` **不抛异常、只记日志、代码继续跑**。
再叠加 `pcall` → 错误完全消失。

```
症状：功能"能跑"，但永远输出错误结果
案例：math.pow 失效 → 8 个检测器全部不报警
对策：关键计算路径加**自检断言**（见下）
```

### 2. erfc 写成 erf（返回了错误函数）

A&S 7.1.26 误写成 `1 - poly·t·exp(-x²)`，正确形式**没有 `1-`**。

```
不报错、值域也正常（都在 0~1）
但 z=3.85 时 p 本应 6e-5、实际 0.5 → BH 校正永远判不出任何人
```

**自检**：
```lua
assert(math.abs(_erfc(0) - 1) < 1e-12)   -- 错版返回 0.0001
```

### 3. 前向引用取到全局 nil

```lua
function _timerKill() print(_nowMs) end   -- 定义在 _nowMs 之前
```

`_nowMs` 是**全局 nil**（非语法错）→ 计时器没销毁 / 返回 0，被 pcall 吞掉。

**规则**：被引用的 local 必须先定义。

### 4. 指标在最可疑时失效

头像框纯度指标：`k < 2` 判"数据不足"跳过。
但 `k = 1` 表示所有好友头像框**完全相同**（熵=0），**恰恰最该报警**。

**教训**：边界条件要单独检查其语义，不能只按"样本量不足"处理。

### 5. 经验 p 值不是 p 值

`rank / m` 是**名次**不是概率，最小值 `1/m`，**永远过不了 BH 门槛**。

### 6. Split 跳过空字段

```lua
string.gmatch(line, "[^,]+")   -- "a,,b" 得 2 个而非 3 个
```

负权重的 `-0`、科学计数法 `1e-5` 一旦产生空串就全乱。**必须重写解析器。**

### 7. 归一化参数漏导出

只导出权重不导出 `mean/std` → **Lua 端算出的分数全是垃圾，而且不报错**。
导出格式必须包含 `MU` / `SD` 行。

## 三、算法/统计类坑

### 1. 验证集不做分层抽样

作弊样本少时随机划分 → 验证集可能全干净 → **accuracy 虚高到没意义**。
**必须分层抽样。**

### 2. 标签传播过度合并

26 节点 → 合并成 1 簇 → 依赖簇的指标**恒为 1**（失去区分力）。
**修正**：边权阈值 + 连通分量，才切出两个完整小号簇。

### 3. MAD 被污染

无锚点时，MAD 被 37% 的小号污染，z 压到 1.67。
设 8 个锚点后 p 降到 1e-7，BH 正常触发。

**结论**：鲁棒统计量（中位数/MAD）在**污染率 > 30%** 时失效，需要可信锚点。

### 4. 多重比较：8 个检测器各自 α=0.05 → 误报率 34%

```
1 - 0.95^8 = 34%
```

**解法**：SPRT 序贯检验累积对数似然比 + BH 校正。
默认需累积 **6.68 nat**（≈800:1 似然比）才处罚，
单次视角突变只给 0.5–3.0 nat → 不会误判。

再叠加**半衰期衰减**（3600s），正常行为自然归零，不留永久污点。

## 四、语法/语义类坑

### 1. 循环变量赋值（Lua 5.5 会崩）

```lua
for _, s in ipairs(list) do
    s = string.lower(s)   -- 5.5: attempt to assign to const variable
end
```

Lua 5.1 允许，5.5 禁止。**写成新变量**。

### 2. `function matvec.repack()` 编译不过

`function` 是**值，不能被索引**。必须挂在表上：
```lua
function Script._repack(...) end     -- 挂在 Script 上
```

### 3. 顶层 local 撞 200 上限

```
main function has more than 200 local variables
```

挂到模块表上可**净增 0**（见《组件表与脚本规范.md》）。

### 4. `math.random` 不确定性

锁步/确定性重放场景**必须固定种子**，否则各客户端模拟结果不一致。

## 五、自检清单（写数值代码时逐条跑）

```
□ 特殊值：f(0)、f(1)、f(-1) 是否符合定义
□ 单调性：输入增大，输出是否单调
□ 边界：x→±∞ 是否溢出/饱和
□ 往返：encode→decode 是否还原
□ 交叉验证：与 Python/JS 独立实现对比
□ 空输入 / 单样本 / 全相同 三类退化输入
□ 断言关键中间量（不是只看最终结果"像个数字"）
```
