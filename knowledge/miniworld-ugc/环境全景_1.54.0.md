## 六、loadstring 相关（重要澄清）

```
转储中确实存在：loadstring / loadfile / dofile / require
```

**但用户实测 `local f = loadstring("return 1+1")` 返回 nil。**

→ 结论：这些符号被**注册为函数但实现被 stub**，调用返回 nil。
**不可用。**（与旧知识一致，转储存在 ≠ 可用）

同理 `io` / `package` 是**空表**，被 stub。

## 七、Mini 模块（重要修正）

【已测】转储中 `Mini` 表**只有 Array 一个显式字段**（46 项全是 Array 的实现），
**没有** `Mini.String` / `Mini.Number` / `Mini.Item`。

但用户实测 `Mini.String.__className_ == "String"`（50 种无一例外）。

→ 结论：**Mini 表通过元表 `__index` 动态解析类型名**，
转储只抓到显式字段，元表驱动的部分抓不全。

⚠️ **转储 ≠ 完整环境。** 元表驱动的成员不会被序列化出来。
