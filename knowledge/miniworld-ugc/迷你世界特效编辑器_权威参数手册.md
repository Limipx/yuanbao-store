## 〇、先纠正你那份整理里的三处错误

你贴的那份《UGC 自定义粒子特效参数关系整理》**整体方向是对的**（发射器全局 → 粒子出生 → 生命周期演化，这个三段式正确），但混进了不属于迷你世界的参数。

### 错误 1：参数名混了网易《我的世界》

文档里这几项——

| 你文档里的 | 实际出处 |
|---|---|
| `emissionrate` 发射速率 | **网易 MC Studio** 特效编辑器 |
| `activetime` 连续发射时间 | 网易 MC Studio |
| `inactivetime` 发射冷却时间 | 网易 MC Studio |
| `numparticles` 最大粒子数量 | 网易 MC Studio |
| `offset/time` 发射路径 | 网易 MC Studio |

**迷你世界特效编辑器的字段是 Unity 粒子系统风格**，名字完全不同：

```
Duration(持续时间)  Looping(循环播放)  Prewarm(预启动)  StartDelay(延迟时间)
StartLifetime(存在时间)  StartSpeed(初始速度)  StartSize(初始缩放)
StartRotation(初始旋转)  StartColor(初始颜色)  GravityModifier(重力乘数)
RateOverTime(发射速率)  MaxParticles(最大粒子数量)  Shape(发射器形状)
SimulationSpeed(播放速度)  SimulationSpace(移动坐标系)  ScalingMode(缩放模式)
TrailsMode(拖尾)  ColorOverLifeTimeMode(颜色随生命周期)  AutoRandomSeed(自动随机种子)
```

依据：官方 `EffectObject` 类文档（studio.miniworldgame.com / studio.mini1.cn 双站一致）。

### 错误 2：曲线采样的说法只对了一半

> 你写："曲线采样是基于发射器的运行时间，不是粒子自己的存活时间"

**这条是对的**，但漏了另一半——编辑器里存在**两套**曲线：

| 曲线类型 | 采样基准 | 面板位置 |
|---|---|---|
| 【曲线】模式 | **发射器运行时间** | 各数值参数的模式下拉里选"曲线" |
| 【随 XXX 变化】 | **粒子自身生命周期** | 生命周期区（速度/缩放/旋转/颜色/透明度随生命变化） |

两套都存在，别只记一套。

### 错误 3：补充的"API 映射表"少了大半

你列了 10 个字段映射，官方 `EffectObject` 实际有 **40+ 个属性**（含拖尾、爆发、裁剪、循环区间等），完整表见 §2。

## 一、特效编辑器是什么（官方事实）

来源：官方 1.51.0 更新日志（dev-wiki.mini1.cn）、创作者学院公告

- **上线版本**：1.51.0（2025-10-30 前后）
- **能力**：自定义编辑特效，**支持多节点**（一个特效下可挂多套粒子系统），**100+ 粒子参数**
- **调用方式**：触发器 / 脚本
- **官方示例效果**：烟花、落叶、拖尾、闪光
- **入口**：创作工具 3.0 → 资源库 → 特效 → 新建；或沙盒工坊搜"特效尝鲜包"直接导入现成的（樱花飘落、发光蝴蝶、真实雪花、萤火虫、吹泡泡、打铁花）

### 自定义贴图的三步流程（官方视频实证）

```
① 创作工具3.0 → 上传图片
② 新建【特效材质】→ 替换贴图
③ 新建【特效】→ 渲染模块 → 材质 → 选刚做的材质
```

### 面板层级（你截图实证）

```
自定义特效_6（根）
├─ 粒子特效
└─ 粒子特效(1)
```

一个根下可挂多套粒子系统，各自独立设置，互不干扰。

## 三、面板模块与参数（实证 + 推测已标注）

### 3.1 顶部（实证：你截图 + 视频教程）

| 参数 | 说明 |
|---|---|
| 自动随机种子 | 开＝每次效果不同；关＝可复现（刀光、符文关掉） |
| 播放速度 | 整体快慢倍率，1＝正常 |

### 3.2 模块列表（实证：你截图）

```
渲染 / 发射器 / 发射器形状 / 噪声 / 序列帧 / 拖尾
```
默认只显示部分，**需要勾选才会展开**（拖尾就是默认不勾的）。

### 3.3 发射器模块

| 参数 | 值范围/典型 | 来源 |
|---|---|---|
| 持续时间 | 0.05~3600，爆炸 0.2 / 环境 3~10 | 官方 Duration |
| 循环播放 | 开/关 | 官方 Looping |
| 预启动 | 仅循环时生效 | 官方 Prewarm |
| 延迟时间 | 0~1000 | 官方 StartDelay |
| 发射速率 | 每秒粒子数，飘落 6~15 / 雨 150~250 | **推测**（Unity 通用名 RateOverTime） |
| 最大粒子数量 | 手机端 ≤300 | 官方 MaxParticles |

### 3.4 粒子出生参数

| 参数 | 说明 | 来源 |
|---|---|---|
| 存在时间 | 单颗粒子寿命 | 官方 StartLifetime |
| 初始速度 | 出生速率，方向由形状决定 | 官方 StartSpeed |
| 初始缩放 | 100＝基准，可三轴独立 | 官方 StartSize |
| 初始旋转 | 三轴角度 | 官方 StartRotation |
| 翻转概率 | 0~1，沿 YZ 平面镜像 | **推测**（Unity Flip） |
| 初始颜色 | 4 种模式 | 官方 StartColor / StartColorGradient |

### 3.5 生命周期区

| 参数 | 说明 | 来源 |
|---|---|---|
| 速度随时间 | X/Y/Z 线性速度；含**轨道速度** | 官方 VelocityOverLifeTimeLinear |
| 旋转随时间 | 转速 | 官方 RotationSpeed |
| 缩放/透明度曲线 | 随生命变化 | Unity 通用 |
| 颜色随生命周期 | 模式 + 最小/最大色 | 官方 ColorOverLifeTimeMode |
| 爆发 Brust | Time/Count/Cycles/Interval | 官方 ParticleEmissionBurst |

### 3.6 发射器形状（实证：视频教程）

形状选项含：**球形 / 半球体 / 圆锥 / 圆柱 / 盒体 / 圆环 / 圆形 / 方形面**

关键子项（视频实证 + 实测经验）：

| 子项 | 要点 |
|---|---|
| **旋转 X = -90** | 半球体、圆环、圆形默认**朝侧面**；改 -90 才平铺（贴地/当天穹） |
| **半径厚度 = 0** | 粒子严格排在同一球面上（整齐）；留厚度＝分散（自然） |
| 球面方向 | 半球体时决定朝内还是朝外 |
| 发射在形状内部 | 开＝内部分散；关＝只在外表面（会成"壳"） |
| 半径/夹角 | 球=半径；圆锥=夹角；方形=长度 |
| 方向随机 | 0~1，混合随机方向 |

### 3.7 噪声（实证：视频提到，参数名推测）

位置噪声 / 速度噪声 / 旋转噪声，各有 **频率**（抖动快慢）与 **强度**（抖动幅度）。
典型：萤火虫 频率0.25 强度2.5；火焰 频率1.2 强度0.6。

### 3.8 序列帧（实证：视频 + Unity 通用）

1. 上传序列图 → 特效材质 → 渲染里替换
2. 勾选序列帧，填**水平分段 / 垂直分段**（9×9 图就填 9 和 9，非序列图填 0）
3. 两种播放：**随机显示** / **随生命周期变化**（变化速度、起始索引、结束索引、循环）

### 3.9 拖尾（实证：视频教程，参数名全部确认）

| 参数 | 典型值 |
|---|---|
| 拖尾长度 | 星轨 0.03 / 人物拖尾 0.08~0.15 / 刀光 0.02 |
| 拖尾宽度 | 两常量间随机 4~10；刀光要 15~30 |
| 拖尾颜色 | 两颜色间随机 |
| 粒子缩放影响拖尾宽度 | 一般关；刀光开 |
| 最小顶点距离 | 越小越平滑，0.05 常用 |
| 拖尾材质 | 渲染模块的第二个材质槽 |

### 3.10 渲染（实证：你截图）

| 参数 | 说明 |
|---|---|
| 材质 1 / 材质 2 | 材质2 给拖尾用 |
| 渲染模式 | 广告版（永远面向摄像机）/ 水平面（贴地）/ 默认材质包 |
| 最小/最大粒子尺寸 | 限制屏幕像素尺寸，防太近糊 |
| 渲染对齐 | 摄像机平面 |
| 翻转 | 贴图镜像 |
| 混合模式 | 想更亮用"叠加" |

## 四、4 种数值模式 + 4 种颜色模式

**数值**（Unity MinMaxCurve 四模式，官方 `RangeInfo` 类型印证）：

| 模式 | 行为 |
|---|---|
| 常量 | 所有粒子同一值 |
| 两个常量间随机 | 出生时在 A、B 间抽一个，之后不变 |
| 曲线 | 随**发射器运行时间**采样 |
| 两个曲线间随机 | 出生时随机选一条曲线，全程跟随 |

**颜色**：颜色 / 两颜色随机 / 颜色梯度 / 两颜色梯度随机

## 五、播放特效（脚本 + 触发器）

### 5.1 脚本（官方签名，6 个参数）

```lua
World:playParticalEffect(x, y, z, particleId, scale, ptime, bUsePlayerViewRange)
--  x,y,z        位置
--  particleId   特效ID（资源库 Ctrl+C 复制）
--  scale        缩放，1＝原大小
--  ptime        播放时长(秒)。>0 时循环播放到时间结束；填 0 只播一次
--  bUsePlayerViewRange  是否按视野裁剪
```

挂道具/玩家：

```lua
Backpack:PlayShortCutItemParticle(playerid, itemid, effectid)      -- 手持道具
Backpack:PlayShortCutIxEffect(playerid, effectid, scale)           -- 玩家身上
Backpack:StopShortCutItemEffect(playerid, itemid, effectid)        -- 停止
```

### 5.2 触发器（不用写代码）

动作 → 特效 → **"在位置上播放特效"**
　位置对象：事件中的位置 / 区域随机位置 / 自定义位置
　特效类型：模板库选，或填自制特效 ID
　数值：缩放；时长：>0 会循环到时间结束

⚠ **循环特效不会自己消失**，必须用"删除位置上的特效"动作。

### 5.3 特效事件（用来做联动）

```
TriggerEvent.ParticlePosOnCreate         特效创建在任意位置   eventobjid,x,y,z,effectid
TriggerEvent.ParticlePlayerOnCreate      特效创建在任意玩家
TriggerEvent.ParticleMobOnCreate         特效创建在任意生物
TriggerEvent.ParticleObjectOnCreate      特效创建在任意对象
TriggerEvent.ParticleItemOnCreate        特效创建在任意掉落物
TriggerEvent.ParticleProjectileOnCreate  特效创建在任意投掷物
TriggerEvent.ParticleEntityOnCreate      特效创建在任意实体
```

## 七、性能红线

| 场景 | 上限 |
|---|---|
| 单特效最大粒子数量（手机） | ≤ 300 |
| 全屏所有特效合计 | ≤ 800 |
| 中低端机保守值 | ≤ 150 |

**实际同屏数 = 发射速率 × 存在时间**，这个值必须 ≤ 最大粒子数量，否则会被截断（画面变稀）。

卡顿排查顺序：砍最大粒子数量 → 砍发射速率 → 缩短存在时间 → 关噪声 → 关拖尾 → 关序列帧。

## 八、已知限制（诚实版）

1. **没有"脚本写入特效资源"的接口** —— 脚本只能播放已做好的特效，参数必须在面板里点。所以本脚本的定位是"告诉你每个格子填什么"，不是自动生成特效文件。
2. **面板参数名部分为推测**（发射速率、翻转概率、噪声频率/强度等），官方只给了脚本侧字段名。真机面板名字若对不上，以面板为准，逻辑不变。
3. **特效编辑器是 1.51.0 新功能**，官方文档尚未单开页面，两个 wiki 站的 EffectObject 字段清单本身就有出入，说明仍在迭代。
4. 序列帧的"水平/垂直分段"必须和你实际贴图的切分一致，填错会只显示一小块。
