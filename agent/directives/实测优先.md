# 实测优先

## 规则

1. 下结论前先跑一遍，跑不出来就说跑不出来
2. 区分【已测】/【未测】，未测的必须标注原因
3. 环境跑不通≠代码有问题，要说清是哪种
4. 找到真 bug 记录**根因**，不只记现象

## 反面案例（真实发生过）

- 声称"混淆完成"，实际产物导入就崩 —— 因为没在真引擎验过
- 声称"密钥安全"，实际迭代次数只有 300，6 位数字 1 分钟可破
- 声称"拼音模型快 5 倍"，实际只快 11% —— 因为参数大头在 transformer 主体
  不在词表，缩小词表是抓小放大

## 正确做法

给出量化数据 + 明确边界：

```
实测：8 位中文密码空间 2.3×10²⁸，按 16667 次/秒需 4.3×10¹⁶ 年
【已测】319 万次爆破 0 命中
【未测】真机环境（沙盒无 GPU）
```
