## 5. 迷你世界引擎铁律 ★必读

违反任一条，表现为**导入成功、看得到函数名、调用返回 nil**，极难排查。

### 5.1 组件表结构

```lua
local Script = {}

Script.propertys = { ... }
Script.openFnArgs = { ... }     -- 只写这一个，不要写 openFunctions

function Script:OnStart()
    SELFREF = self                -- 保存 self
    -- 初始化数据在这里
end

return Script
```

**九条铁律**

1. **定义的表中不能有非函数字段** —— 初始化数据必须在 `OnStart` 执行
   - `propertys` / `openFnArgs` 是引擎保留名，在白名单内
   - **多加 `Script.openFunctions` 就会触发**"非函数字段"警告（v3 就是这么踩的）
2. **不要写 `Script.openFunctions = Script.openFnArgs`** —— 那是混淆工具的扫描策略，不是脚本写法
3. **读属性值走 `self[x]`**，绝不读 `Script.propertys[x].default`
4. `OnStart` / `OnDestroy` / `OnUpdate` **永不改名**（引擎按名字调用）
5. `__index` 等元方法**永不改名**
6. `propertys` / `openFnArgs` **必须留顶层**，搬进函数体 = 加载期读到空
7. 元数据区字符串**不能用 `_DEC`**，用 `string.char(...)`（纯全局，可达）
8. 登记表键必须与函数名**同步改名**
9. `arrayWrapper` 必须定义在 `openFnArgs` **之前**

### 5.2 数组属性

```lua
-- 定义
tableIds = {
    type = Mini.Array,
    itemType = Mini.String,
    default = Mini.Array(Mini.String, "id1", "id2", ...),
    displayName = "二维表ID组",
    customDisplayName = "表ID",
}
-- 读取：self.tableIds，1-based，#arr 可取长度
```

- 用户明确要求**用数组，不要字符串分割**（纠正过两次）
- `arrayWrapper` 只用于开放函数返回数组

### 5.3 二维表 playerId 语义

```
playerId = nil 或 0  →  全局房间变量
playerId = 非0数字   →  私人个人变量（传了永远返回 nil）
```

**读二维表一律传 nil 或 0。**

### 5.4 时间 ★用户反复强调

- **`os.timeMs()` 存在，返回毫秒**
- **`os.clock` 不存在，用了必崩**
- `os` 只有 `date` / `time` / `timeMs`

**凡是按时间推进的调度，一律用 `os.timeMs` 绝对时间戳，
绝不用每帧累加固定步长模拟时间。**（TTS v3.1 就是栽在这，Tick 间隔与真实时间脱节）

### 5.5 self:ThreadWait

**参数是【秒】，不是 tick。** 必须在协程里调用。

```lua
local co = coroutine.create(function()
    for i = 1, 100 do
        doSomething(i)
        self:ThreadWait(0.05)
    end
end)
coroutine.resume(co)
```

### 5.6 引擎元数据：转储存在 ≠ 可用

- `loadstring` 转储里有，**实测返回 nil**（被 stub）
- `collectgarbage` 真机是**坏 stub**：`type()` 检测通过但调用报 nil
- `Mini` 只有 `Array` 一个显式字段，其余走元表
- `bit` 模块一定存在；`bit32` 不存在
- Lua 5.1：无 goto、无整数除法，用全局 `unpack`

**判断能否用，必须实测，不能只看转储清单。**

### 5.7 广播

- 消息 ID **必须预设**（触发器里新建），不能自定义
- 参数数量不限，**可传 table**
- 三套机制别混用：
  `PushEvent`（同对象组件）/ `PushCustomEvent`（全房间）/ `PushCloudServerMsg`（跨房间）
- 云服广播延迟 **10 秒**

### 5.8 KV 表

- key ≤ **50 字节**，只能用 94 个可打印符号（**不支持空格**）
- value ≤ 200 万字节，**支持比特流**
- **只有云服表有阻塞接口和限流**，房间/个人表没有
- 现行云服接口：`Data.Map:GetValueAndBlock(v,p,k)` / `SetValueAndBlock` / `RemoveValueAndBlock`
- ⚠️ `Data.Map:GetMapValue` **在真机不存在**（只在 API 转储里）—— 房间/个人版曾因此全崩

### 5.9 脚本大小

手机端导入 **1MB 以下**，电脑端 **20MB**。（权重在二维表里，不受此限。）
