## loadstring 澄清（重要）

转储中**确实存在** `loadstring` / `loadfile` / `dofile` / `require`，
但用户实测 `loadstring("return 1+1")` 返回 **nil**。

→ **被 stub：符号在，实现空。不可用。**
同理 `io` / `package` 是空表。

**转储存在 ≠ 可用。** 这是本次最重要的认知修正。
判断可用性**必须实测**，不能只看转储清单。

## Mini 模块修正

转储中 `Mini` **只有 Array 一个显式字段**（46 项），
没有 String / Number / Item。但用户实测 `Mini.String.__className_=="String"`。

→ **Mini 走元表 `__index` 动态解析，转储抓不到元表驱动成员。**

Mini.Array 完整方法见 `环境全景_1.54.0.md`（33+ 个方法）。
