# 迷你世界 UGC3.0 · 两套脚本上下文

> 更新：2026-10-09　来源：官网 dev-wiki.mini1.cn + 8个官方组件模板 + 1.54.0 环境转储
> 【已测】模板文件来自游戏内"新建组件"的实际产物

## 结论：官方有两套并行的写法，别混用

| | 触发器脚本（旧） | 组件脚本（新，UGC3.0 推荐） |
|---|---|---|
| 入口 | 全局函数 | `local Script={}` … `return Script` |
| 注册事件 | `ScriptSupportEvent:registerEvent([=[Player.ClickBlock]=], 函数名)` | `self:AddTriggerEvent(TriggerEvent.PlayerClickBlock, self.Handler)` |
| 回调签名 | `function 名(event)` | `function Script:Handler(event)` |
| 属性 | 无 | `Script.propertys`（面板可配） |
| 开放函数 | 无 | `Script.openFnArgs`（触发器可调用） |
| 定时器 | 需自己实现 | `self:DoPeriodicTask` / `self:DoTaskInTime` |

**新项目一律用组件脚本。**

## 桥梁：TriggerEvent 常量 = 字符串事件名

这是本次最重要的发现。转储里 **252 个 TriggerEvent 常量全部有值，值就是字符串事件名**：

```
TriggerEvent.ActorCreate   = "Actor.Create"
TriggerEvent.GameHour      = "Game.Hour"
TriggerEvent.PlayerMountActor = "Player.MountActor"
TriggerEvent.PlayerClickBlock = "Player.ClickBlock"   ← 由命名规律推出
```

所以两套写法**完全等价**：

```lua
-- 旧（触发器脚本）
ScriptSupportEvent:registerEvent([=[Player.ClickBlock]=], OnClick)

-- 新（组件脚本）
self:AddTriggerEvent(TriggerEvent.PlayerClickBlock, self.OnClick)
```

【已测】转储中 252/252 个 TriggerEvent 常量均带字符串值。
【未测】`TriggerEvent.PlayerClickBlock` 的确切值未在抽样中直接出现，
        由 `ActorCreate="Actor.Create"` 等 25 个样本归纳的命名规律推出。

## 组件脚本骨架（8 个官方模板的共同结构）

```lua
local Script = {}

-- ① 属性定义（引擎加载期读，面板显示）
Script.propertys = {
    varNum = { type = Mini.Number, default = 99, displayName = "数值" },
    varStr = { type = Mini.String, default = "你好！", displayName = "文本" },
}

-- ② 开放函数配置（触发器里可选到）
Script.openFnArgs = {
    Add = {
        returnType = Mini.Number,                 -- 不填=无返回值
        displayName = "函数别名",                  -- 不填=显示函数名
        params = { Mini.Number, Mini.Number },    -- 不填=无参数
    },
}

-- ③ 启动
function Script:OnStart()
    self:AddTriggerEvent(TriggerEvent.PlayerClickBlock, self.OnPlayerClickBlock)
    self.task = self:DoPeriodicTask(self.OnPeriodicTask, 3)
end

function Script:OnPeriodicTask() print("定时器执行") end

-- ④ 开放函数
function Script:Add(a, b)
    if a and b then return a + b end
end

return Script   -- 必须有
```

## 组件的 self 方法（引擎注入，转储里查不到）

【已测】以下均**不在** 1.54.0 环境转储中——它们是引擎注入到组件实例上的方法，
转储只抓 `_G` 全局环境，抓不到实例方法。来自 8 个官方模板的实际使用。

### 事件监听

```lua
self:AddTriggerEvent(TriggerEvent.Xxx, self.Handler)        -- 触发器事件
self:AddTriggerEvent(TriggerEvent.UIButtonClick, self.OnBtnClick, "元件id")  -- 第三参=元件id，不填=监听全部按钮
self:AddTriggerEvent(TriggerEvent.PlayerInputKeyDown, self.OnKeyW, KeyCode.W)
self:AddEvent(ObjectEvent.Xxx, self.Handler)                -- 个体事件（对象自身）
self:AddCustomEvent("msgui123", self.OnCustomEvent)         -- 监听自定义广播
```

### 事件发送

```lua
self:PushEvent("msg123", 1, 2, 3)       -- 实例内部事件（仅本实例内可接收）
self:PushCustomEvent("msg123", 1, 2, 3) -- 自定义广播（跨实例）
```

### 定时器

```lua
self:DoTaskInTime(function() print("延时执行") end, 5)      -- N秒后执行1次
self.task = self:DoPeriodicTask(self.OnPeriodicTask, 3)      -- 每3秒
local task = self:DoPeriodicTask(fn, 3, 5, 10)               -- 5秒后开始，每3秒，共10次
self.task:Pause()  self.task:Resume()  self.task:Cancel()
```

### 组件/对象操作

```lua
self:GetComponent("HP")        -- 取本对象其他组件，返回组件实例
self:GetGameObjectId()         -- 世界组件/实体组件用
self:GetId()                   -- 对象 id
```

### 属性访问

```lua
self.varNum          -- 直接读写 propertys 里定义的属性
self.varStr = "x"    -- 可写
```

## 官方 8 种组件类型

| 组件 | 挂载对象 | 模板里的默认属性 | 典型用途 |
|---|---|---|---|
| 世界组件 | 世界节点 | varNum | 全局玩法逻辑、玩家点击方块 |
| 玩家组件 | 玩家 | varNum / varStr | 玩家相关 |
| 生物组件 | 生物 | varNum / varStr | 生物行为 |
| 实体组件 | 实体 | varNum | 右键交互 |
| 方块组件 | 方块 | dropItem / dropItemNum | 方块被破坏掉落 |
| 界面组件 | UI | 无 | UI 按钮、自定义事件 |
| 状态效果组件1 | 状态 | addHp / interval | 周期加血 |
| 状态效果组件2 | 状态 | addHp | 一次性加血 |

## 常见模板代码片段

```lua
-- 方块被破坏 → 生成掉落物
function Script:OnBlockRemove(event)
    GameObject:CreatePrefab(ObjType.DropItem, self.dropItem,
        event.x, event.y, event.z, self.dropItemNum)
end

-- 点方块 → 创建嘟嘟鸟并设血量
local objs = GameObject:CreatePrefab(ObjType.Mob, 3400, event.x, event.y+1, event.z)
if objs and objs[1] then
    local hpCmp = objs[1]:GetComponent("HP")
    if hpCmp then hpCmp.hp = 120 end
    Actor:SetAttr(objs[1]:GetId(), RoleAttr.CurHp, 120)
end

-- 周期加血 + 特效
Actor:AddHp(self:GetGameObjectId(), self.addHp)
Actor:PlayBodyParticleById(self:GetGameObjectId(), 1005, 1)
```

## 事件参数（官网 developers.mini1.cn/wiki/event.html）

九类事件，参数形式统一：

| 类 | 例 | 参数 |
|---|---|---|
| 世界 | 背包物品变化 | blockid, itemid, itemnum, x, y, z |
| 游戏逻辑 | 世界小时变化 | hour |
| 玩家 | 玩家死亡 | eventobjid, shortix, x, y, z |
| 生物 | 生物死亡 | eventobjid, toobjid, actorid |
| 方块 | 被创建 | blockid, x, y, z |
| 道具 | 掉落物被创建 | eventobjid, itemid, defaultvalue, x, y, z |
| 特效 | 特效被创建 | effectid, x, y, z |
| UI | 界面被打开 | eventobjid, CustomUI |
| 其他 | 购买会员 | eventobjid |

**玩家点击方块**（模板注释中明确）：
```
event.eventobjid  event.blockid  event.x  event.y  event.z
```

## 运行时模型（官网原文）

- 每个地图的脚本在**主机端**运行
- 游戏状态每 **50ms** 更新一次 = **1 tick**
- 事件由引擎分派到脚本

⚠️ 这意味着：热路径代码每个 tick 都可能跑，性能敏感。
