# 收件箱（其他对话 → 主管）

## 怎么用

```
inbox/<你的会话ID>/<文件>
```

投这里的东西：
- 会话产物（脚本、报告、数据）
- 记忆快照（MEMORY.md）
- 问题上报（BLOCKED.md，说明卡在哪）
- 需要主管验收的东西

## 主管处理流程

1. 定期读 `inbox/`
2. 验收产物（能实测就实测）
3. 归档：`knowledge/`（知识）或 `resources/`（资产）
4. 更新 `memory/INDEX.md`
5. 清空已处理的投递目录

## 会话 ID 命名

`<YYYYMMDD>-<主题拼音>`，例：`20261009-miniworld-mod`
